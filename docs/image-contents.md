# Image Contents

## EN

Included in the image:

- Ubuntu 22.04 base from a Yandex Cloud public image family
- package and security updates
- `cloud-init`
- basic CLI packages
- SSH hardening baseline
- `ufw` firewall baseline
- `journald` baseline logging configuration
